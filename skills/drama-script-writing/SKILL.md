# 短剧/漫剧原创 IP 剧本创作

## 何时使用

用户要创作或打磨短剧/漫剧剧本，包括：

- 原创故事创意、logline、故事梗概
- 全剧大纲、人物关系、分集梗概
- 单集剧本、台词、反转设计、钩子设计
- 把已有创意 / 素材改编为短剧结构
- 泛化的"帮我写个短剧 / 做个剧集企划"需求

**分镜拆解、beat board、视频提示词不在本 skill 范围**（见 drama-storyboard skill）；角色视觉设计走 drama-character-design，场景/世界观视觉走 drama-scene-worldview——本 skill 是它们与分镜的**共同上游**。

## 原创 IP 红线（最高优先级）

本 skill 的目标是产出**可成为自有 IP 的原创剧本**，不是仿写。红线先于一切技巧：

- **必须原创**：世界观、角色名、标志性台词、桥段具体表达，全部不得复刻现有影视 / 动漫 / 小说 / 游戏 IP
- **禁止换名复刻**：改名不构成原创；借鉴"结构套路"（三幕、反转类型、卡点位置）可以，抄"具体表达"不行
- **主动规避现实**：不得以在世真实人物为原型（含影射）、不得使用真实品牌 / 企业 / 机构名（可用"某集团""甲方公司"指代）
- **合规红线**：涉政敏感、色情低俗、犯罪细节教学、真实案件受害者信息 → 拒绝该方向并给出替代创意，不写"擦边"版本
- **出稿自检**：核心设定写完后搜一遍是否与已知 IP 撞车；发现相似**换设定**，不是换名字

## 原创定位四件套（写剧本前必做）

借鉴 shanyin-screenwriting-master 的人物设计法 + 短剧行业"角色三角"：

- **logline（一句话故事）**：主角 + 欲望 + 障碍 + 反转钩子（"被夺产的养女为查母亲死因回到豪门，发现仇人是养她长大的父亲"）
- **原创差异化卖点**：这个故事"别人没讲过"的是什么？——靠题材组合（悬疑×非遗）、身份反差、规则创新（独有的世界设定）立住，而非靠更狠的情绪
- **主角三角**：**前史**（什么造就了 TA）/ **欲望**（想要什么）/ **冲突**（什么挡着）——三者齐备角色才立得住，也是角色 skill 做形象定位的输入
- **类型与情绪曲线**：类型标签 + 目标情绪峰值位置（爽点 / 甜点 / 悬点的分布），情绪节奏是留存的生命线

**定位四件套经用户确认后才写大纲**（与角色 skill「定稿前不写锚点」同一原则）。

## 结构规范（按格式分流）

### 短剧（默认，单集 60–90 秒）

**四段循环：钩子 → 冲突 → 高潮 → 卡点**

| 位置 | 要求 |
|---|---|
| 开场 3 秒 | 冲突锚定，不铺垫不抒情（开场铺背景超 10 秒流失约 40%） |
| 第 15 秒前 | 冲突必须升级一次 |
| 中段 | 只写"谁 + 说了什么 + 做了什么"，对话要狠（短剧卖情绪，不写氛围） |
| 约 40 秒 | **必须有反转**（无反转基本过不了审） |
| 最后 10 秒 | 留钩子，不圆满——"就在这时，门开了……" |
| 每 30 秒 | 埋一个悬念点，防止走神 |

- 单集字数 **150–220 字**（对应 60–90 秒），超了就是节奏拖
- 卡点付费位置：**一卡 8–12 集**（铺垫期待）、**二卡 26–30 集**（引爆充值）；不得每集都设付费点（每集 3 次弹窗 → 24h 流失可达 70%）

### 长剧集 / 漫剧（叙事完整优先）

- 三幕结构 25% / 50% / 25%（Setup / Confrontation / Resolution），中段含中点转折与低谷
- 全剧至少 **9 个可视化 beat**（关键叙事锚点），分布三幕——它们同时是后续分镜的输入
- 人物弧光：主角初态 → 被打破 → 代价 → 终态，每一阶段有对应 beat

### 反转设计

- 四类套路：**身份反转 / 关系反转 / 事件反转 / 真相反转**
- **同类反转不得连续使用**（连续 10 集同类反转 → 观众麻木）；建立"反转类型轮换表"
- 每个反转必须有**前置埋线**（观众回看能找到伏笔），无埋线的反转是硬拗

## 输出物分层（画布节点）

用 `upsert_prompt_node` 建节点（`prompt` 作节点标题、`content` 为正文，Markdown 可）：

| 层 | 节点 | 标题示例 |
|---|---|---|
| 一 | logline + 原创定位四件套 | `原创定位 · <剧名>` |
| 二 | 全剧大纲（人物关系 + 分集梗概 + 反转轮换表 + 卡点位置） | `全剧大纲 · <剧名>` |
| 三 | 单集剧本（一集一节点） | `EP01 <集标题> · <剧名>` |

- 节点组织：`connect_nodes` 从大纲节点连向各集节点；`arrange_nodes(along_edges)` 分层（大纲居左、集向右展开）
- 单集剧本用**标准影视格式**：场景编号 / 场景标题（内景·地点·时间）/ 动作描述 / 角色名 + 对话 / 转场

## 执行步骤

1. **收集创作参数**（ask_user 结构化选项 + 其他可编辑，一次性问全）：
   - **类型**：A 都市情感 / B 悬疑 / C 逆袭爽剧 / D 古风 / E 玄幻 / F 甜宠 / 其他（请说明）
   - **格式**：A 短剧（60–90 秒/集）/ B 漫剧（叙事完整）/ C 短片（3–10 分钟）
   - **集数**：A 8–12 集 / B 24–30 集 / C 60 集以上 / 其他
   - **目标平台**：A 短视频平台 / B 短剧 App / C 自有渠道（影响卡点位置与时长）
   - **创意来源**：开放描述（每剧不同不预设，作为原创起点）
2. **原创定位**：`recall_memory` 查已有 IP bible 防与本项目其他剧重复；产出 logline + 差异化卖点 + 主角三角 + 情绪曲线，**用户确认定稿**
3. **全剧大纲**：人物关系、分集梗概、反转类型轮换表、卡点位置；建节点
4. **单集剧本**：逐集写，视觉优先格式（见提示词/写法小节）；一集一节点；按需 `set_node_text` 局部修订
5. **节点组织**：`connect_nodes` 大纲 → 各集；`arrange_nodes(along_edges)` 分层
6. **QA 闸门自检**：逐集过 5 道 gate，报告 PASS/REVISE/REJECT
7. **登记 IP bible**：`save_memory` 存 logline / 主角三角 / 世界观要点 / 人物名录 / 反转轮换表 / 各节点 id，供角色与场景 skill 直接取用

## QA 闸门

- **Gate 1 原创性**：角色名、设定、标志性台词是否与已知 IP 撞车；是否出现真实人物 / 品牌 / 机构——违规即 REJECT 改设定
- **Gate 2 钩子强度**：开场 3 秒是否有冲突、每集结尾是否留钩、有无"钩子太慢"（背景铺垫超 10 秒）
- **Gate 3 结构合规**：单集字数在 150–220 区间、反转位置约 40 秒、反转类型无连续重复、卡点位置符合集数规划
- **Gate 4 视觉可拍性**：无抽象心理描写（"她感到恐惧"✗ → "她的手指抠进掌心，指甲泛白"✓）；长剧集是否齐 9 个可视化 beat
- **Gate 5 人设一致**：台词与行为是否符合主角三角与人物名录；反派是否有"极致恶行 + 阶段性胜利"、主角是否每集有至少一次有效反击或推进

**评审结论**：PASS 交付 / REVISE 局部重写（指出哪一 gate 哪一集哪一项）/ REJECT 重做。REVISE/REJECT 时不虚构已修复。

## 常见踩坑对照表（行业实证）

| 踩坑 | 后果 | 对策 |
|---|---|---|
| 钩子太慢 | 开场铺背景 >10 秒，流失约 40% | 第一句就是冲突 / 反常识 |
| 付费点过密 | 每集 3 次弹窗，24h 流失可达 70% | 只在一卡（8–12 集）、二卡（26–30 集）设卡点 |
| 反转疲劳 | 连续同类反转，用户麻木 | 建反转类型轮换表，四类交替 |
| 高潮点后移 | 高潮从第 5 分钟推迟到第 7 分钟，留存 -23% | 情绪曲线前置，早给爽点 |
| 写成小说 | 全是心理与氛围，无法转分镜 | 视觉优先：写动作、写台词、写可见物 |
| 角色扁平 | 只有标签没有欲望 | 主角三角齐备（前史/欲望/冲突） |

## 与角色、场景、分镜 skill 的交接

- 本 skill 的 IP bible 是**全链路上游**：角色 skill 用主角三角做形象定位，场景 skill 用世界观要点做场景档案，分镜 skill 用人物名录 / 情绪曲线做资产解析与镜头节奏
- 剧本里首次出场的角色须给**规范外观描述**（供角色 skill 锁定锚点）；场景出场须标注内/外景与时段（供场景 skill 建档案）；情绪峰值位置（供分镜 skill 对齐镜头节奏）
- 剧本改动后：若角色名 / 世界观变化，同步更新 IP bible 并提示用户相关视觉资产可能需重做

## 规则与边界

- **原创性红线不可协商**，涉政 / 色情 / 犯罪教学类方向直接拒绝并给替代
- 不虚构已完成的工作；不声称"已过审""必爆"
- 篇幅：用户没要求就一次只写到用户要的层（logline / 大纲 / 单集），不自动写满全剧
- **分镜拆解、beat board、视频 / motion 提示词不在本 skill 范围**（分镜见 drama-storyboard skill）

## 写作要点

- **视觉优先**：抽象心理 → 可拍动作；"她感到困惑和恐惧" ✗ → "她瞪大眼睛，手指颤抖着翻动纸页，汗珠从额头滑落" ✓
- **短剧卖情绪**：对话本身就是冲突载体，写"谁说了什么"，不写内心独白
- **首因一致**：角色首次出场给完整外观描述，后续沿用同一组识别符（与角色 bible 对齐）
- **一句话能复述**：每集梗概必须能用一句带反转的话说清，说不清就是结构没立住
- **钩子句式库**（原创化使用，勿照抄）：悬念动作（"就在这时，门开了"）、身份揭穿（"您隐藏的身份，藏不住了"）、认知颠覆（"他说的下一句话，让我彻底崩溃"）
