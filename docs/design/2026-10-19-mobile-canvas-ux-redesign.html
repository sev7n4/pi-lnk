Draft · 待评审≤767px 画布页签基线 d6cb79ce（2026-10-19）PC 端不动

1. 现状：PC 按钮原样上移的两个现场

左：画布态——左侧竖轨五钮常驻（hover 才肯藏的「常驻/隐藏」对触屏无意义）、右上视口胶囊、底部 composer。右：多选态——贴选区下沿一字排开 13 个 30px 图标钮，分组色/布局/导出还是 hover 下拉。

2. 目标：六态线稿

三区结构不变（全局壳 / 画布世界 / composer 脊柱）。变化：左缘竖轨 → 左下 ＋ FAB + 全宽新建 sheet；多选工具条 → 底部动作条 + 更多 sheet；长按 → 44px 上下文 sheet；视口胶囊换肤 --lnk-*。

3. 手势地图（按断点分流）

P0-1 的根因：pan-on-drag=[1,2] 让 d3-zoom filter 拒掉所有触屏 touchstart（TouchEvent 无 button 字段）。修复 = 移动端 panOnDrag=true + 应用层多选模式，PC 逐字不变。
