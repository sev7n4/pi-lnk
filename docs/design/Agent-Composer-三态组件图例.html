说明：本图例为规格 §5.5 的可视化附件。所有 composer 表面上的控件（＋/模型/语音/发送/◎）均按 §2 原则 7 为无背景 ghost 控件，不引入内部嵌套面板。两层契约：composer 表面内 = 草稿内容（ref 芯片 + 输入文本，芯片行位于文本上方、无独立面板背景，表面随内容生长）；表面上方 = 仅系统层（生成状态行、插话轻选项、PC 首屏样例 chips）。红色「停止」块为生成态唯一强调色例外。移动端「＋」置于条内左侧（非条外独立按钮），整条视觉即「一个 composer 条 + 其上几个组件」。◎ 在输入/生成态可见、空态隐藏（键入 @ 任意态仍可触达）。
