0 · 使用说明（先读）

文档定位

线稿中的布局、尺寸、令牌、状态是落地对照基准；文案与图标为示意。冲突裁决顺序：规格文字判据 > 本线稿 > 个人审美。验收走查以「截图 ↔ 线稿」并排比对。

两层契约（规格 §2 原则 7 / §5.5）

composer = 单一干净表面（PC 整卡 / 移动端单条），文本直接落表面、无内嵌输入框描边；表面内 = 草稿（ref 芯片 + 文本）+ 无背景 ghost 控件；表面上方 = 仅系统层（状态行 / 插话选项 / PC 首屏样例 chips）。focus 以表面边框 → border-focus + ring 表达。

4 · 组件规格明细

组件尺寸 / 令牌状态可达性
composer 表面（PC 卡 / 移动条） PC：radius-xl surface-raised border-default shadow-md padding space-3；移动：radius-full shadow-sm 高 48（堆叠态圆角 20） focus-within：border→border-focus + 2px accent-subtle ring 容器 role="group" aria-label="消息输入"
文本区 直接落表面，无描边；PC min 96 / max 200（B7、P2-3.2）；text-base/22 placeholder = text-muted；生成态换排队语义文案（P0-1.2） PC Enter 发送 / Shift+Enter 换行；移动仅按钮发送（P0-1.1）
ghost 控件（＋/模型/🎙/发送/思考chip） PC 32×32 / 移动 44×44 命中（视觉 24，透明 padding）；radius-md；色 text-muted hover→text-primary；active scale .96；发送就绪 accent-text；禁用 text-disabled；任何状态不加底色 每个都有 aria-label（B19 只修 1 处 → 全覆盖）；:focus-visible ring
◎ 画布节点引用 22px 视觉圆，圆心 = 表面左顶点（translate(-50%,-50%)）；命中 PC 32 / 移动 44；色 accent-text 无底 输入/生成态可见；空态隐藏（透明度 0 + pointer-events none，保留 @ 键盘路径） aria-label="引用画布节点"；点开的选择器用 listbox 语义（P2-4.1 同源）
停止块 32×32（PC）/ 44 命中（移动，视觉 14 方块）；red-600 填充 + text-on-accent；radius-sm 生成态替换发送，坐标/层级不变（P1-3.2） aria-label="停止生成"；aria-live="polite" 播报阶段变化
ref 芯片（草稿层） 高 24；surface-sunken 底 + border-subtle + radius-sm；缩略图 18×18 radius-xs hover 边框→border-strong；拖拽中 shadow-md + scale 1.02 移除钮 aria-label="移除引用 X"；芯片行 role="list"
状态行（系统层） ≤24px；text-2xs text-muted；进度条 3px accent 不确定态用 indeterminate 动画；成本未知则隐藏对应段（P1-3.1） role="status" aria-live="polite"
样例 chips / 插话选项（系统层） 高 28；surface-raised（样例）/透明（插话）+ border-default；radius-full text-sm hover 边框→border-strong 字→primary；点击填充不发送 样例容器 role="listbox" 或按钮组 + 方向键

5 · 状态切换与动效

切换变化规格
空闲 → 输入提示文字→光标；◎ 淡入；移动端条生长出芯片行duration-base(200ms) + ease-decelerate；◎ opacity 0→1 + scale .8→1；条高用 grid-rows 过渡，禁 height 魔法数
输入 → 生成中发送→停止交叉替换；状态行滑入按钮 crossfade duration-instant(100ms)；状态行 translateY(-6px)→0 + fade duration-base
生成中 → 完成/失败停止→发送恢复；状态行移除反向同参数；产出收据行出现（P1-4.1，另属消息流）
按住说话（移动空闲）条边框→border-focus + 电平呼吸录音时长/电平反馈；上滑取消；reduced-motion 下只变边框色不脉冲
全局—只动 transform / opacity；@media (prefers-reduced-motion: reduce) 全部禁用（本文档已内置示例）

6 · 落地遵循清单（走查逐项打勾）

结构红线

  • composer 是单一表面：无内嵌输入框描边、无内部分区/嵌套面板 §2 原则 7
  • 移动端 ＋ 在条内左侧；无条外独立按钮、无独立控制行 P1-5.3/5.4
  • ref 芯片在表面内文本上方；状态行/样例/插话在表面上方 两层契约 §5.5
  • composer 区段无 hover-only 选点球；◎ 三态按门控可见 P1-2.3
  • C 抽屉（＋内）= 本地上传/资产库/参数预设，不含画布选节点 P1-2.1
  • 停止键与发送同坐标同层级 P1-3.2

视觉红线

  • ghost 控件任何状态不加底色（唯一填充 = 停止红块）§2 原则 7
  • 零新增 hex / rgba / text-white / bg-[#]；只消费 --lnk-* L2/L3 P1-6.1
  • 每个 L2 令牌深浅同名成对；文字色一律实色 design-token.test.ts
  • 文字对比度：muted 档浅 ≥4.5:1 / 深 ≥4.5:1（用 -secondary/-muted 实色档）P0-2
  • 阴影走 --lnk-shadow-*，浅色无硬黑投影 P0-3
  • 字号/间距/圆角全部令牌化，无 10/11px 裸值（状态行用 text-2xs）P0-2.2

交互红线

  • 移动端主控件命中 ≥44（视觉不变，透明 padding 撑）P0-4.1/4.2
  • 键盘契约：PC Enter 发送；移动回车换行、仅按钮发送；占位符不提键盘 P0-1
  • 语音仅空闲态：按住条=录音、松开填入不提交、上滑取消；输入态无长按语音 P2-2.2 / §5.2
  • ◎ 独立命中区：点击 ◎ 不触发条的语音/切态手势 P1-2.3 实现注记
  • 所有图标按钮有 aria-label；focus-visible 有 ring；mention 菜单 listbox 语义 B19 / P2-4.1
  • 流式插话队列 / 引用芯片拖排 / 双主题 / 停止块四保护项能力不削弱 §6

DO / DON'T 速查

✓ DOfocus 用表面 border→border-focus + ring；hover 用颜色变化；条/卡随内容生长。
✓ DO ◎ 用绝对定位圆心钉在左顶点，并给 ≥44 透明命中区。
✗ DON'T给 ghost 控件加 hover 底色块、把发送做成实心按钮——破坏「无背景」契约。
✗ DON'T把 ref 芯片放回浮层、或在卡内再画一个带描边的输入框——两层契约破坏。
✗ DON'T为省事用 left/top 动画或无限脉冲——掉帧且违反 reduced-motion。
