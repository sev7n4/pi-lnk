## 一、桌面端：对齐六向

选 2~20 个节点 →「整理布局」菜单 → 左对齐 / 水平居中 / 右对齐 / 顶对齐 / 垂直居中 / 底对齐

- [ ] 六个方向各自都生效，**没有哪个方向静默无反应**
- [ ] 对齐后**零压盖**、坐标正确（可开 DevTools 看 position 数值）
- [ ] 含**分组内子节点**一起选中时同样正确（子节点坐标是父相对的，不能差一个父偏移）
- [ ] 选中分组自身（单选一个组）时点对齐**不炸、不静默乱动**

## 二、桌面端：等距分布

选 ≥3 个节点 →「整理布局」→ 水平等距 / 垂直等距

- [ ] **首尾两个节点锚定不动**，只有中间节点移动
- [ ] 相邻包围盒**空隙相等**（目测或量坐标）
- [ ] 只有 2 个节点时点等距**不报错、不动**（少于 3 个是 no-op）

## 三、桌面端：拖拽智能参考线

拖一个节点靠近其他节点的边缘 / 中心

- [ ] 进入 8px 内**出现参考线**（横线 + 竖线）
- [ ] 节点**被吸附**到参考线上
- [ ] 松手后**保持精确对齐**（不被 20px 网格吸附覆盖）
- [ ] 参考线**随缩放/平移跟随**（滚轮缩放后线仍贴在节点边上，不偏移、不脱节）
- [ ] 缩到 50% 以下时参考线**仍横贯整个可视区**（不是只画半屏）
- [ ] **多选拖拽时整批一起动**，批内相对间距不被扯散
- [ ] 拖分组时**不与自己的子节点互吸**

## 四、移动端：行为与桌面一致

移动端「更多」sheet →「整理布局」→ 六向对齐 + 两轴等距

- [ ] 六向对齐**都能点、都能生效**
- [ ] 与桌面端**行为一致**（同样的输入、同样的结果）

## 八、拖拽手感复测（R1 平滑化，2026-10-23 实测反馈专用）

> 背景：首版上线后实测「能用但不丝滑、被吸住、步阶太大」。根因两条：
> ① 吸附几何按 NODE_SIZES **方框兜底**估媒体节点尺寸（16:9 视频真实 320×180
> 被估成 320×320 ⇒ 中心/底边差 70-140px，视觉边没贴线就被弹回）；
> ② prev 参考线**无限粘滞**（吸上后拖到哪都粘着，只有别的线更近才顶掉），
> 且阈值是 flow 坐标不随缩放换算（放大细看时 8px 变 16px 起跳）。
> R1 修复：实测尺寸通道 + 屏幕空间阈值（8px/3px，按 1/zoom）+ 释放带 + 切换余量。

拖一个节点靠近其他节点的边缘 / 中心，重点体会「跟手性」：

- [ ] 拖拽过程**连续无跳变**：没有「突然被弹回去一大截」或「线悬在节点旁边」的情况
- [ ] 吸附发生时**参考线紧贴视觉边缘/中心**（尤其 16:9 视频节点，线不悬空）
- [ ] 拖离参考线时**在约 11px（屏幕）内脱钩**，继续拖不再被粘住（松手即自由）
- [ ] 滚轮**放大到 150%~200%** 后重复上述：吸入距离/脱钩带在屏幕上和 100% 时一样大
- [ ] 缩到 **50% 以下**：吸附仍然有效（不会因阈值太小而失效）
- [ ] 两条邻近边几乎对齐（相距几 px）时慢速拖过中点：**不出现左右/上下反复横跳**
- [ ] 多选整批拖拽：整批一起动，手感与单节点一致

> 既有设计（非本次缺陷）：松手时节点会落 20px 网格（`snapToGrid` 默认开），落格瞬间有 ≤10px
> 的位移是 2026-10-12「拖拽丝滑化」的既定取舍（拖拽中 1:1 跟手、松手才落格），
> 与本次 R1 的「拖拽中吸附」手感无关；可在画布设置里关掉网格吸附做对照。
