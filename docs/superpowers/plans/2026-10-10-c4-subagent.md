# C4 子代理（只读 Explore 型）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 pi-runtime 加 `spawn_subagent` 工具：模型自主派发只读 Explore 子代理（fork 主会话历史），同步阻塞返回最终报告，三件套硬边界（全局并发 2 / turn 预算 30 / 超时 5min）。

**Architecture:** 三层——①`gate/subagent.ts` 纯状态机（常量/白名单/全局并发信号量/SubagentCoordinator 中转）；②`tools/spawn-subagent.ts` 工具（deps 注入 coordinator，fail-soft 语义）；③SessionManager 新增 `runSubagent`（复用既有 `fork()` 的 repo.fork + build(existingFs) 路径，白名单 ensemble 覆盖 + per-entry turnBudgetLimit，await lane.prompt 与超时 race，清理时绝不 releaseHandles——env/repo 与主会话共享）。

**Tech Stack:** TypeScript / vendor pi AgentHarness（SessionRepo.fork、AgentLane.prompt、withCancel）/ node:test + tsx（pi-runtime）/ faux provider 集成测试（C2 同款）。

**Spec:** `docs/superpowers/specs/2026-10-10-c4-subagent-design.md` v1.1.0（八项拍板 §4、机制 §3、Review Focus §5）。

## Global Constraints

- 三件套硬编码不可禁用：`SUBAGENT_MAX_CONCURRENT=2`（全局跨会话）/ `SUBAGENT_TURN_BUDGET=30` / `SUBAGENT_TIMEOUT_MS=300_000`；无 env、无 kill switch（spec §3.4）。
- 白名单是架构硬边界：写域工具物理不在子代理工具表；`spawn_subagent`/`ask_user`/`propose_plan`/`save_memory`/`connect_nodes` 等写族绝不进白名单（spec §3.3）。

```ts
/** C4 子代理三件套与白名单（spec docs/superpowers/specs/2026-10-10-c4-subagent-design.md §3.3/§3.4）。 */
export const SUBAGENT_TURN_BUDGET = 30;
export const SUBAGENT_TIMEOUT_MS = 5 * 60_000;
export const SUBAGENT_MAX_CONCURRENT = 2;
export const SUBAGENT_REPORT_MAX_CHARS = 20_000;

/** 副作用面三类（spec §3.3）：本地只读 + net-egress 进；状态写入/交互/自身排除。 */
export const SUBAGENT_TOOL_WHITELIST: ReadonlySet<string> = new Set([
	"todo_write", "recall_memory", "read_document", "list_model_options", "list_user_assets",
	"get_canvas_summary", "get_canvas_layout", "get_node",
	"list_generation_tasks", "get_generation_status", "get_generation_diagnostic", "list_generation_scenes",
	"web_search", "web_fetch",
]);
export function isSubagentTool(name: string): boolean { return SUBAGENT_TOOL_WHITELIST.has(name); }

export class SubagentSlots {
	#active = 0;
	acquire(): boolean { if (this.#active >= SUBAGENT_MAX_CONCURRENT) return false; this.#active += 1; return true; }
	release(): void { this.#active = Math.max(0, this.#active - 1); }
	get active(): number { return this.#active; }
}

export type SubagentStatus = "completed" | "failed" | "timeout" | "budget_exceeded";
export interface SubagentOutcome { report: string; turns: number; durationMs: number; status: SubagentStatus }
export interface SubagentRunner { runSubagent(piSessionKey: string, task: string): Promise<SubagentOutcome> }

/** spawn 工具与 SessionManager 的解耦中转（PendingToolRegistry 同款装配顺序）。 */
export class SubagentCoordinator {
	private slots = new SubagentSlots();
	private runner?: SubagentRunner;
	attach(runner: SubagentRunner): void { this.runner = runner; }
	tryRun(piSessionKey: string, task: string): { ok: true; promise: Promise<SubagentOutcome> } | { ok: false; reason: "not_attached" | "concurrency_full" } {
		if (!this.runner) return { ok: false, reason: "not_attached" };
		if (!this.slots.acquire()) return { ok: false, reason: "concurrency_full" };
		const promise = this.runner.runSubagent(piSessionKey, task).finally(() => this.slots.release());
		return { ok: true, promise };
	}
}
```
